=== Backup and Recovery



==== Mejoras en cargas de trabajo de Kubernetes

En esta versión, NetApp Backup and Recovery introduce las siguientes mejoras para las cargas de trabajo de Kubernetes:

* *Trident Protect 26.10*: Esta versión incluye Trident Protect 26.10.
* *compatibilidad con los controladores ontap-nas-economy y ontap-san-economy*: ahora puedes proteger las solicitudes de volumen persistente (PVC) aprovisionadas por el controlador NetApp Trident `ontap-nas-economy` (Qtrees) y el controlador `ontap-san-economy` (LUN). Cuando proteges PVC mediante controladores economy, se protege todo el FlexVol o LUN subyacente. Puedes restaurar PVC individuales a partir de estos backups.
* *Alertas compatibles con Kubernetes*: ahora las alertas se envían una vez por cada aplicación de Kubernetes, en lugar de una vez por cada volumen.
* *Compatibilidad con snapshots de grupos de volúmenes*: ahora puedes crear grupos de volúmenes al definir una aplicación de Kubernetes. Los grupos de volúmenes te permiten tomar snapshots de varios volúmenes juntos como un conjunto coherente frente a caídas, lo que garantiza la coherencia de los datos en todos los volúmenes del grupo.
* *Compatibilidad con el almacenamiento de objetos compatible con S3*: ahora puedes realizar copias de seguridad de los recursos y datos de las aplicaciones de Kubernetes en un almacenamiento de objetos compatible con S3 añadiendo las credenciales del destino de la copia de seguridad y configurando las políticas de protección.


Para obtener más información sobre cómo proteger las cargas de trabajo de Kubernetes, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Kubernetes con NetApp Backup and Recovery"^].



==== Mejoras en las cargas de trabajo de ONTAP Volumes

En esta versión, NetApp Backup and Recovery presenta las siguientes mejoras para las cargas de trabajo de ONTAP Volumes:

* *Informes de protección*: NetApp Backup and Recovery ahora permite crear y descargar informes ampliados para cargas de trabajo de ONTAP Volumes.
* *Conservar copias de seguridad al dar de baja un sistema ONTAP*: al dar de baja un sistema ONTAP de NetApp Backup and Recovery, ahora puedes elegir entre descartar los datos de las copias de seguridad anteriores o mantenerlos disponibles para restaurarlos. La documentación de NetApp Backup and Recovery ahora incluye instrucciones para usar la CLI de ONTAP para restaurar los datos conservados después de dar de baja el sistema.


Para obtener más información, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-backup-manage.html#unregister-netapp-backup-and-recovery-for-a-system["Anular el registro de Backup and Recovery para un sistema"^].

Para obtener más información sobre la protección de las cargas de trabajo de ONTAP Volumes, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["Descubre la protección de volúmenes de ONTAP con NetApp Backup and Recovery"^].



==== Mejora de las cargas de trabajo de Oracle Database

En esta versión, NetApp Backup and Recovery introduce la siguiente mejora para cargas de trabajo de Oracle Database:

*Restaurar en una ubicación alternativa*: NetApp Backup and Recovery ahora permite restaurar una base de datos Oracle en una ubicación alternativa (un host registrado diferente).

Para obtener detalles sobre cómo proteger las cargas de trabajo de Oracle Database, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-oracle-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Oracle Database con NetApp Backup and Recovery"^].

=== Backup and Recovery



==== Mejoras en las cargas de trabajo de Hyper-V

En esta versión, las cargas de trabajo Hyper-V introducen las siguientes mejoras:

* *Compatibilidad con NetApp MetroCluster*: NetApp Backup and Recovery ahora te permite proteger VM de Hyper-V replicadas por NetApp MetroCluster.
* *Protección de discos distribuidos para VM SAN*: en configuraciones CIFS y SAN, ahora puedes proteger todos los discos conectados a cada VM de un grupo de protección. Esto incluye tanto archivos distribuidos entre varios volúmenes ONTAP o sistemas de almacenamiento ONTAP (discos distribuidos) como archivos limitados a una sola ubicación.


Para más detalles sobre la protección de cargas de trabajo Hyper-V, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-hyperv-protect-overview.html["Aprende a proteger las cargas de trabajo de Hyper-V con NetApp Backup and Recovery"].



==== Mejora de las cargas de trabajo de Oracle Database

En esta versión, Oracle Database workloads introduce la siguiente mejora:

*Gestión automática de registros de archivo*: durante las operaciones de restauración y clonación de bases de datos, NetApp Backup and Recovery detecta y monta automáticamente los registros de archivo necesarios y luego los desmonta una vez finalizada la operación. Se admiten fuentes de registros de almacenamiento primario, secundario y de objetos.

Para obtener detalles sobre cómo proteger las cargas de trabajo de Oracle Database, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-oracle-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Oracle Database con NetApp Backup and Recovery"].



==== Mejora de las cargas de trabajo de Microsoft SQL Server

En esta versión, las cargas de trabajo de Microsoft SQL Server incorporan la siguiente mejora:

*Cambio en la política de licencias*: ya no se cobran cargos por las copias de seguridad que usan arquitecturas de disco a disco o de disco a disco con fan-out. Los cargos solo se aplican a las copias de seguridad en almacenamiento de objetos, incluidas las que usan arquitecturas 3-2-1 o de disco a almacenamiento de objetos.

Para obtener más información sobre cómo proteger las cargas de trabajo de Microsoft SQL Server, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-mssql-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Microsoft SQL Server con NetApp Backup and Recovery"].

==== Mejoras en las cargas de trabajo de ONTAP Volumes

En esta versión, las cargas de trabajo de ONTAP Volumes incorporan las siguientes mejoras en fase de vista previa:

* *Compatibilidad mejorada para dark sites*: NetApp Backup and Recovery para dark sites ahora ofrece las mismas capacidades de protección de datos de ONTAP Volumes que NetApp Backup and Recovery. Esta mejora incluye servicios actualizados de copia de seguridad, restauración y gestión de trabajos, así como una nueva base de datos de metadatos. Durante una actualización, los datos existentes de la base de datos se conservan y se migran automáticamente. Después de la actualización, revisa los registros de auditoría para verificar que la migración se completó correctamente. NetApp Backup and Recovery para dark sites solo admite cargas de trabajo de ONTAP Volumes.
* *Cancelar trabajos de restauración de volúmenes*: ahora puedes cancelar trabajos de restauración de ONTAP Volumes en curso desde la página de supervisión de trabajos, lo que facilita la gestión de los trabajos de larga duración o de los que se ejecutan con lentitud.
* *Mejora en los informes del estado de indexación de volúmenes*: El panel de control de ONTAP Volumes ahora informa del estado de indexación con más precisión al introducir el estado  `Not Applicable` para los volúmenes y las copias de Snapshot que no son aptos para la indexación. El estado  `Not Indexed` ahora se reserva para los volúmenes que están esperando a ser indexados, y los detalles del volumen ahora muestran el estado de indexación por Snapshot con un texto al pasar el cursor que explica por qué un volumen o una copia de Snapshot no se indexará.
* *Compatibilidad con AFX de NetApp*: ahora puedes proteger volúmenes alojados en clústeres AFX de NetApp de 2 y 4 nodos.


Para obtener más información sobre la protección de las cargas de trabajo de ONTAP Volumes, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/prev-ontap-protect-overview.html["Descubre la protección de volúmenes de ONTAP con NetApp Backup and Recovery"].



==== Mejoras en cargas de trabajo de Kubernetes

En esta versión, las cargas de trabajo de Kubernetes introducen las siguientes mejoras:

* *Trident Protect 26.09*: Esta versión incluye Trident Protect 26.09.
* *Control de acceso basado en roles (RBAC) con granularidad a nivel de clúster y de espacio de nombres*: durante la detección de clústeres de Kubernetes, puedes controlar el acceso a los recursos seleccionando un proyecto o una carpeta para asociarlos con el nuevo clúster. También puedes registrar espacios de nombres específicos para el control de acceso. Esto permite un control de acceso más granular tanto a nivel de clúster como de espacio de nombres.
* *Restaurar archivos y carpetas*: Ahora puedes restaurar o descargar archivos y carpetas concretos a partir de las copias de seguridad de aplicaciones basadas en máquinas virtuales de Kubernetes.


Para obtener más información sobre cómo proteger las cargas de trabajo de Kubernetes, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Kubernetes con NetApp Backup and Recovery"].

En esta versión, las cargas de trabajo de Hyper-V incorporan la siguiente mejora:

*Restaurar una copia de seguridad del almacenamiento de objetos en una ubicación alternativa*: Ahora puedes restaurar máquinas virtuales de Hyper-V, archivos y carpetas desde el almacenamiento de objetos a una ubicación de almacenamiento alternativa.

Para más detalles sobre la protección de cargas de trabajo Hyper-V, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-hyperv-protect-overview.html["Aprende a proteger las cargas de trabajo de Hyper-V con NetApp Backup and Recovery"].



==== Mejoras en cargas de trabajo de Kubernetes

En esta versión, las cargas de trabajo de Kubernetes introducen las siguientes mejoras:

* *Trident Protect 26.08*: Esta versión incluye Trident Protect 26.08.
* *Reintentos de copia de seguridad*: Ahora puedes activar los reintentos de copia de seguridad y configurar el número de intentos y los intervalos entre ellos como ajustes avanzados en las políticas de protección de Kubernetes.
* *Éxito parcial del backup*: Ahora puedes configurar ajustes avanzados en las políticas de protección de Kubernetes para que el backup continúe cuando fallen recursos individuales, permitiendo que las tareas de backup se completen como parcialmente exitosas. Esto te permite restaurar los recursos respaldados incluso si algunos recursos fallan durante la operación de backup.
* *Copias de seguridad coherentes con los fallos y coherentes con la máquina virtual*: El servicio NetApp Backup and Recovery for NetApp Console ahora permite configurar políticas de protección que crean copias de seguridad o instantáneas coherentes con los fallos o coherentes con la máquina virtual. También puedes personalizar cómo se realizan las congelaciones de la máquina virtual durante la operación de protección.
* *Volver a conectar el clúster de Kubernetes tras un cambio de IP del agente de Console*: el servicio Backup and Recovery para NetApp Console ahora te permite volver a conectar un clúster a su agente de Console si la dirección IP del agente cambia.
* *Migra el clúster a un nuevo agente de Console*: el servicio Backup and Recovery for NetApp Console ahora te permite migrar un clúster a un nuevo agente de Console si el agente original falla o se elimina, lo que garantiza una protección de aplicaciones sin interrupciones.


Para obtener más información sobre cómo proteger las cargas de trabajo de Kubernetes, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-kubernetes-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Kubernetes con NetApp Backup and Recovery"].



==== Mejora de las cargas de trabajo de Oracle Database

En esta versión, las cargas de trabajo de Oracle Database introducen las siguientes mejoras:

* *Restauración de bases de datos conectables (PDB)*: ahora puedes restaurar bases de datos conectables (PDB) y espacios de tabla de PDB de forma individual, incluida la recuperación a un momento específico.
* *Clon de una base de datos conectable (PDB)*: ahora puedes clonar una sola PDB en una base de datos contenedora (CDB) de destino ya existente y, si quieres, excluir PDBs cuando clones una base de datos contenedora completa.


Para obtener detalles sobre cómo proteger las cargas de trabajo de Oracle Database, consulta https://docs.netapp.com/us-en/data-services-backup-recovery/br-use-oracle-protect-overview.html["Descubre cómo proteger las cargas de trabajo de Oracle Database con NetApp Backup and Recovery"].
